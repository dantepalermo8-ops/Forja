# FORJA — Entrenamiento

Paquete definitivo preparado para subir directamente a la raíz de un repositorio de GitHub y publicar con GitHub Pages.

## Archivos

- `index.html` — aplicación FORJA.
- `manifest.json` — configuración PWA.
- `service-worker.js` — caché/offline.
- `icon-180.png` — icono generado con la imagen proporcionada.
- `icon-192.png` — icono generado con la imagen proporcionada.
- `icon-512.png` — icono generado con la imagen proporcionada.
- `icon.png` — copia compatible de 512×512.

## Publicación

1. Sube **todos los archivos** a la raíz del repositorio.
2. En GitHub entra en **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona `main` y `/ (root)`.
5. Guarda.

No hace falta cambiar nombres ni crear carpetas.

## Importante

Los iconos `icon-180.png`, `icon-192.png` y `icon-512.png` usan la imagen que se proporcionó para este paquete.
